# Peike's GTA VI Gids

Tips, easter eggs, een kaart en Xbox-instellingen voor GTA VI, gemaakt voor Peike.

- **App downloaden:** ga naar *Releases* → **PeikeGTA6.apk**.
- **Updates:** de app haalt nieuwe inhoud op uit `content.json` in deze repository. Een nieuwe APK is daarvoor niet nodig.
- Spoilervrije fan-gids, geen officiële Rockstar-app.
